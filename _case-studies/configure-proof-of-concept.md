title: Configure Proof of Concept
description: >-
  Atlas grew into Configure, a working marketplace for pre-construction
  procurement, designed and built in one year alongside KLH Engineers'
  internal development team.
problem: >-
  The Atlas design sprint proved the concept. Now KLH needed working software
  to put in front of investors and industry partners. Specifying and buying
  building products still meant emailed PDFs, phone calls, and pricing nobody
  could see, and no off-the-shelf tool connected the designers, contractors,
  and vendors doing the work.
role: >-
  I integrated with KLH's internal development team as the product's designer,
  designing each feature directly in the app as Razor mockup pages and
  shipping the production front end in HTML and CSS on the Blazor Server
  stack, backed by a CSS token design system, user testing sessions, and
  design documentation for the developers building against it.
outcome: >-
  Configure secured over $1.5M in funding within its first year of development
  and earned industry buy-in from leaders including Autodesk.

solutions:
  - title: project workspace
    description: >-
      Everything in Configure hangs off a project. The workspace collects a
      project's products, requests, and quotes in one place, and every request
      shows its collaborators and vendors up front so it's obvious who is in
      the conversation.
    media: /assets/images/case-studies/configure-proof-of-concept-project-workspace.png
  - title: product search
    description: >-
      Contractors search a live catalog by keyword, product series, and
      distance from the job site. Spec sheets and Revit files download
      straight from a result card, which used to mean finding the right rep
      and waiting on an email.
    media: /assets/images/case-studies/configure-proof-of-concept-product-search.png
  - title: product details
    description: >-
      A product page carries the manufacturer's full description, attribute
      tables, equipment tags, and unit pricing on one screen. This is the same
      information that once lived across PDF catalogs, now structured and
      searchable.
    media: /assets/images/case-studies/configure-proof-of-concept-product-details.png
  - title: product configurator
    description: >-
      Building products are rarely bought off the shelf. The configurator
      walks a user through each parameter of a product code and highlights the
      valid options at every step, so a correct, orderable code comes out the
      other end without a call to the manufacturer.
    media: /assets/images/case-studies/configure-proof-of-concept-product-configurator.png
  - title: create a request
    description: >-
      A request gathers the documents, deadline, and collaborators for a need
      into one form. What used to be an email thread with attachments becomes
      a trackable record with a due date.
    media: /assets/images/case-studies/configure-proof-of-concept-create-a-request.png
  - title: request details
    description: >-
      Vendors answer a request with quotes that all land in the same thread.
      Status flags make the state of each quote readable at a glance, and the
      original ask stays pinned at the top, so a months-long procurement
      conversation lives in one place instead of an inbox.
    media: /assets/images/case-studies/configure-proof-of-concept-request-details.png
  - title: quote details
    description: >-
      A quote breaks down its products, additional line items, and package
      pricing, with approve and reject actions right on the page. Comparing
      vendors stopped meaning reconciling differently formatted PDFs by hand.
    media: /assets/images/case-studies/configure-proof-of-concept-quote-details.png
  - title: vendor product management
    description: >-
      Vendors maintain their own catalog through a built-in PIM, with tabs for
      attributes, configurations, rules, accessories, and applications.
      Accurate data comes straight from the source, and the same records power
      the configurator's rules.
    media: /assets/images/case-studies/configure-proof-of-concept-vendor-product-management.png
